# AtliQ Hardwares - Sales & Financial Analytics 

## 📌 Project Overview
This repository contains an end-to-end Excel data analytics project for **AtliQ Hardwares**, a globally operating consumer electronics company. The primary objective of this project is to evaluate the company's financial performance and sales trends across multiple global markets, sub-zones, and fiscal years to enable data-driven decision-making for executive and supply chain stakeholders.

## 📊 Key Reports & Dashboards
This project includes two primary financial reporting views:

**1. Profit & Loss (P&L) by Market (FY 2021)**
* Provides a comprehensive breakdown of Net Sales, Cost of Goods Sold (COGS), Gross Margin, and Gross Margin Percentage (GM %) for over 20 global markets.
* All financial values are standardized and reported in USD to maintain global consistency.

**2. Gross Margin % by Quarters (Sub-Zone)**
* Tracks quarterly profitability trends (Q1-Q4) across three fiscal years: 2019, 2020, and 2021.
* Segments performance data by sub-zones, including ANZ (Australia/New Zealand), India, NA (North America), NE (Northern Europe), ROA (Rest of Asia), and SE (Southern Europe).

## 💡 Key Business Insights
Based on the FY 2021 data modeling:
* **Top Revenue Drivers:** India generated the highest Net Sales at $161.26M (32.0% GM), followed by the USA at $87.78M (37.0% GM) and South Korea at $48.97M (35.9% GM).
* **Profitability Leaders:** New Zealand achieved the highest Gross Margin percentage at 48.2%, followed by Japan at 46.5% and the United Kingdom at 45.1%.
* **Margin Fluctuations:** In FY 2020, India's Gross Margin dropped to an average of 32.2% across the year, compared to 42.4% in FY 2019. 

## 🛠️ Tech Stack & Skills Demonstrated
* **Tool:** Microsoft Excel
* **Data Modeling:** Power Pivot, Data Modeling, Relationship Building
* **ETL:** Power Query (Data cleaning, transformation, and standardizing currencies)
* **Analytics:** Advanced Pivot Tables, DAX for Excel, Conditional Formatting

## 🚀 How to Use This Repository
1. Download the `AtliQ_Hardwares_Financial_Analytics.xlsx` file from this repository.
2. Open the file in Microsoft Excel (2016 or newer recommended for Power Pivot compatibility).
3. Navigate to the respective report tabs to interact with the filters (Region, Sub_zone, FY) and analyze the metrics.
